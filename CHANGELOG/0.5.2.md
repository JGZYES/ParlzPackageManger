# PMM v0.5.2

## 新增
- **`pmm doctor` / `pmm diagnose`**：一键健康检查，自动定位"装完不生效"类问题并给出可执行修复命令——
  - 当前 `pmm` 解析到哪个二进制 vs 运行的二进制（PATH / `hash -r`）；
  - PATH 里混入的 Windows 侧 `/mnt/…` pmm 目录（WSL 继承泄漏）；
  - 各注册表镜像可达性（默认/优先镜像是否 404/挂起）；
  - 已装包完整性（`root/bin/<包>` 是否缺失）；
  - 语言包是否偏旧、缺新 key。
  只读、不改任何东西；发现问题返回非 0 并汇总 `doctor: 发现 N 个问题`。

## 变更 / 修复
- **`mirror` 并入 `setting`**：`pmm mirror` 的所有子命令迁到 `pmm setting mirror …`（list/check/add/use/remove）；
  `pmm setting mirror <name>` 仍为设为当前镜像；顶层 `pmm mirror` 移除。
- **i18n 回退**：语言包缺失某 key 时回退到内置 zh-CN 表，旧 `.pjson` 不再显示裸 `msg.xxx`；
  并同步 `zh-CN`/`en-US` 语言包（新增 `desc.clean`、`msg.dep-satisfied`、`msg.err.conflict`、
  `msg.cache-cleared`、`msg.self-up-to-date`、`desc.doctor`、`msg.doctor-issues` 等）。
- **镜像回退提速**：`http_get` 超时降到 `--max-time 15 --connect-timeout 8`，镜像源抖动时快速失败并落到健康镜像，
  不再阻塞 60 秒（修复 `self-update`/`install` 卡在 `sz.pmm.parlz.com`）。
- 文档（index/mirror/cli）改为 `pmm setting mirror …` 写法。
