# PMM v0.3.4

## 修复
- **RPM 安装稳定性**：
  - 解包前用 `mkdir -p` 创建 stage 目录，避免因目录不存在导致 `fopen` 失败、数据被静默跳过（之前报 `cp: cannot stat '.../.pmm-rpm-stage/.': No such file`）。
  - 解包结果若为空（如压缩格式判断错误 / 工具缺失）会直接报错并返回失败，不再“假装安装成功”。
  - `pmm_cpio_unpack` 补齐 `<dirent.h>` 头文件。
- 顺带整理 RPM / DEB 的无依赖自解压链路（纯 C 解析 rpm 头 + cpio，无需系统 `cpio/rpm/rpm2cpio/alien`）。

## 说明
- Linux 默认装 `/usr/local/bin`；`-p <路径>` / `PMM_INSTALL_DIR` 覆盖。

## 安装
```bash
# Linux/macOS 一键
curl -sSL https://pmm.parlz.com/install.sh | bash
# Windows：解压 pmm-0.3.4-windows-amd64.zip，pmm.exe 加入 PATH
```
