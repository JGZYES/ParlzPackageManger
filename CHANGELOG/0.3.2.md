# PMM v0.3.2

## 新增 / 修复
- **deb / rpm 无依赖自解压安装**：pmm 用 C 自解析
  - `.deb`：解析 ar 容器取出 `data.tar.*`（支持 gz / zst / xz / bz2），`tar` 解到 `/`，无需 `dpkg/ar/alien`。
  - `.rpm`：解析 rpm 头取出 cpio payload，`gzip/zstd` + `cpio` 解到 `/`，无需 `rpm/rpm2cpio/alien`。
  - 因此 CentOS 可装 deb、Debian 可装 rpm。
- **官网下载指向 `/releases/v<版本>/`**（修正 URL 带 `v` 前缀、rpm 命名无 `-1`）。
- 下载区/发布区配套 `pmm/pmm.exe/zip/deb/rpm/apk/pkg.tar.zst/install.sh`。

## 说明
- Linux 程序默认装 `/usr/local/bin`；`-p <路径>` / `PMM_INSTALL_DIR` 覆盖。
- 解 deb 需系统有 `tar`；zst 解压需 tar 支持 zstd（或先 `apt/yum install zstd`）。

## 安装
```bash
# Linux/macOS 一键
curl -sSL https://pmm.parlz.com/install.sh | bash
# Windows：解压 pmm-0.3.2-windows-amd64.zip，pmm.exe 加入 PATH
```
