# PMM v0.3.0

首个正式版（Stable）。跨平台 C 语言包管理器（Windows / Linux / macOS），带官网、镜像站与 Git 源码浏览。

## 亮点
- **Linux 下载程序默认装到 `/usr/local/bin`**（系统级、在 PATH）；仅当 `-p <路径>` 或 `PMM_INSTALL_DIR` 指定目录时才覆盖。
- 官网：首页 + 特性 / 安装 / 下载 / 服务状态 / 源码 六页；服务状态多端点探测；GitHub 风格源码浏览 + 发布会（Assets 可折叠、左侧标签高亮）。
- 官方源：`pmm.parlz.com`（香港）、`sz.pmm.parlz.com`（深圳）。

## 0.2.9 → 0.3.0 变更
- 安装目录默认改为系统级（Linux/macOS `/usr/local/bin`）。
- 源码浏览页 `git.php` 完善：本地仓库、Releases 视图（GitHub 同款）、内联样式。

（其余功能沿用 v0.2.9：依赖解析、并发分片下载、search/info/verify、cache、`--git repo@tag`、`-dpkg`/`-msi`、rpm 打包、github 资产平台修复。）

## 安装
```bash
# Linux/macOS 一键
curl -sSL https://pmm.parlz.com/install.sh | bash
# Windows：解压 pmm-0.3.0-windows-amd64.zip，pmm.exe 加入 PATH
```
