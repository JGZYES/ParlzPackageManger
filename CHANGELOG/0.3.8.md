# PMM v0.3.8

## 修复
- **`pmm setting lang <loc>` 下载语言包失败**：之前只试第一个注册表镜像（默认 `sz.pmm.parlz.com`），
  而该镜像源当前不提供 `/mirror/lang`（返回 404），导致 `pmm setting lang zh-CN/en-US` 一直「下载失败」。
  现在改为**按优先级逐个镜像尝试**，第一个能返回 `.pjson` 的即生效（备源 `pmm.parlz.com` 正常，会自动回退成功）。

## 优化（install.sh）
- **清旧缓存**：装完执行 `hash -r`，并对 bash/zsh 打印明确提示，避免旧 shell 命中已删除的旧 pmm 路径
  （`~/.pmm/root/bin/pmm`）而报 `No such file or directory`。
- **检测命中路径**：安装后 `command -v pmm` 检查当前 shell 会解析到哪个 pmm；若不是刚装的版本，
  打印精确的三步修法（`export PATH` → `hash -r` → `which pmm && pmm -v`），并识别 `/mnt/` 下
  由 WSL 继承 Windows PATH 带进来的 Windows 侧 pmm。

## 说明
- 语言包实际存放在 `web/mirror/lang/{locale}.pjson`（当前含 `zh-CN`、`en-US`）。
