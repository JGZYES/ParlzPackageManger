# PMM v0.5.4

## 新增
- **`pmu` 同名同创作者可续版本**：发布时记录包 `owner`（上传者邮箱）；同一创建者可上传**新版本**，
  同版本重复上传被拒，不同创建者改同包被拒（409）。
- **精确取版接入 per-version 索引**：`pmm install <pkg>==<ver>` 优先取 `dists/<pkg>/<version>.json`，
  404 时回退到包级 variants。
- **`pmm fetch <pkg>…`**：只下载进缓存不安装。
- **`pmm cache list|clean`**：列出/清空下载缓存。
- **`pmm install --offline`（`-o`）**：仅用缓存安装，不联网；未缓存则提示先 `pmm fetch`。

## 修复
- **下载进度条实时显示**：改为画到 stderr 或 stdout 中实际为终端的那个，每帧刷新；不再只在 ctrl+c 时输出。
  同时移除静默的并行下载路径，大文件也显示进度条。
- **下载报错措辞**：由“下载语言包 … 失败”改为通用“下载 %s 失败”（对 .pdm 也正确）。
- **旧 `/packages` base 自动回退到 `/dists`**：注册表拉取在 base 以 `.../mirror/packages` 结尾时，
  额外尝试 `.../mirror/dists`，让旧 mirror.ini 用户在新镜像布局下也能工作。
- **en-US 预安装**：把 `en-US.pjson` 内嵌为内置表，`LANG=en-*` 且未装语言包时即显示英文。
- **install.sh 统一安装路径**：改为装到 `~/.pmm/root/bin/pmm`（与 `pmm install pmm` 自升级一致），
  并把 `~/.pmm/root/bin` prepend 到 `~/.bashrc`，避免两处安装“串”。

## 说明
- 镜像已采用 `dists/` + `files/<首字母>/<pkg>/` 布局；`pmm.parlz.com` 已同步，`sz.pmm.parlz.com` 待同步。
- 语言包（zh-CN/en-US）补齐 cache/fetch/offline 等新 key。
