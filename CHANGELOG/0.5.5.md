# PMM v0.5.5

## 新增:ppdm (ParlzPackageDevManager) v0.0.1
独立的开发/发布工具,随本 release 一并产出(资产 `ppdm` / `ppdm.exe`),与 PMM 二进制版本独立。
- `ppdm register <email> <password>`:注册账号(本地算术人机验证)
- `ppdm login` / `logout` / `whoami`
- `ppdm pack <dir> [out]`:把含 `pdm-control` 的目录打包成 `.pdm`
- `ppdm update`:下载最新 ppdm 到 `~/.ppdm/bin/ppdm`
- `ppdm ./xxx.pdm` / `ppdm publish ./xxx.pdm`:发布包(自动生成 json)
- 服务端 `web/ppdm`(默认 `https://pmm.parlz.com/ppdm`),配置 `~/.ppdm/config`

## 说明
- ppdm 版本号独立(0.0.1),不受 PMM 版本影响。
- 原名 `pmu` 已改名为 `ppdm`。
