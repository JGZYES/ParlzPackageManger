# PMM v0.5.3

## 镜像目录重构
`web/mirror/` 由 `packages/<pkg>.json + packages/<pkg>/*.pdm` 改为:
```
web/mirror/
  dists/
    packages.json              # 包名列表
    <pkg>.json                 # 每包最新+variants(客户端主入口)
    <pkg>/<version>.json       # 每版本元数据
  files/
    <首字母>/<pkg>/<ver>-<os>-<arch>.pdm   # 实际 .pdm,按首字母分桶
```
- 注册表 base 由 `.../mirror/packages` 改为 `.../mirror/dists`。
- 客户端拉取元数据(`/dists/<pkg>.json`、`packages.json`)与下载(`files/<首字母>/<pkg>/…`)均适配;语言包推导兼容新 base。
- 所有既有包已迁移(files/ 下按 `a,b,c…` 首字母分桶)。

## 其他
- `pmu` 发布改为写入新布局(`files/<首字母>/<pkg>/` + `dists/<name>/<version>.json`)。
- 文档/示例/镜像 README 更新。
