# PMM v0.3.3

## 修复
- **RPM 安装不再依赖系统的 cpio/rpm/rpm2cpio/alien**：
  - 新增纯 C 的 cpio 解包器，解析 newc(070701) / crc(070702) / odc(070707) 归档，
    直接把 rpm payload 里的文件解到目标目录。
  - 因此在没有 `cpio` 的 Debian/Ubuntu 上也能直接装 rpm（之前报 "need rpm, rpm2cpio+cpio or alien"）。
- **RPM 按真实压缩格式选解压器**：不再是「默认 gzip」，而是读取 payload 的魔数，
  gzip / zstd / xz / bzip2 / lzma 自动匹配（修复 RHEL9/Fedora 的 zstd 包报 "not in gzip format"）。
- 解压失败现在会真正报错并返回失败，不会再「假装安装成功」。

## 说明
- 安装 rpm 只需系统有 gzip / zstd / xz / bzip2 / lzma 中任意一个（几乎所有 Linux 都至少带一个），
  加上 pmm 内置的 cpio 解包器，即可无依赖安装。

## 安装
```bash
# Linux/macOS 一键
curl -sSL https://pmm.parlz.com/install.sh | bash
# Windows：解压 pmm-0.3.3-windows-amd64.zip，pmm.exe 加入 PATH
```
