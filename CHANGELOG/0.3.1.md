# PMM v0.3.1

## 新增
- **跨发行版自解压安装 deb/rpm**（不做格式转换）：
  - `.deb`：优先 `dpkg -i`；否则用 `ar` 取出 `data.tar.gz` 解到 `/`；`alien` 兜底。
  - `.rpm`：优先 `rpm -Uvh`；否则用 `rpm2cpio|cpio` 解出 payload 到 `/`；`alien` 兜底。
  - 这样 CentOS 能装 `.deb`、Debian 能装 `.rpm`，无需安装 alien 转换。
- **`pmm install -rpm <x.rpm>`**：强制按 RPM 安装（任意 Linux 发行版）。
- 新增 Alpine `.apk` 与 Arch `.pkg.tar.zst` 打包 + 联网安装处理（沿用 v0.3.0）。

## 说明
- 下载/安装程序默认装到 `/usr/local/bin`（Linux/macOS），`-p <路径>`/`PMM_INSTALL_DIR` 覆盖。

## 安装
```bash
# Linux/macOS 一键
curl -sSL https://pmm.parlz.com/install.sh | bash
# Windows：解压 pmm-0.3.1-windows-amd64.zip，pmm.exe 加入 PATH
```
