# PMM v0.5.0

## 版本说明
- 跳过 0.4.0–0.4.9,直接发布 0.5.0(用户要求)。

## 新增镜像包(.pdm)
- **nginx** 1.30.4(linux amd64 + aarch64)——Debian 官方二进制,`nginx -v` 可验证。
- **apache** 2.4.68(linux amd64 + aarch64)——Debian 官方 apache2 二进制(依赖系统 libapr/apr-util)。
- **docker** 29.8.0(linux amd64)——官方静态 CLI(`docker --version` 可验证)。
- **docker-ce** 29.8.0(linux amd64)——官方静态引擎(CLI + dockerd + containerd + runc)。
- 全部已注册进 `web/mirror/packages`(各自 `.json` + `.pdm`),并加入聚合 `packages.json`。

## 说明
- nginx / apache 为动态链接的主二进制:在含对应系统库的 Linux 上可运行;`~/.pmm/root/bin` 已加入 PATH。
- docker / docker-ce 为官方静态二进制,自包含、跨发行版可跑;dockerd 需 root 才能作为 daemon 启动。
- aarch64 的 docker/docker-ce 视官方静态包下载情况补充(当前网络不稳,可能仅 amd64)。
