# PMM v0.5.6

## 新增
- **`pdm-control` 可选字段**:
  - `LibraryPath: true|false`：`true` 时 pmm 自动把该包的 `lib/` 目录写入 `~/.bashrc` 的
    `LD_LIBRARY_PATH`（按包**可选**，默认 `false`，普通工具包不污染环境），装库后新 shell 里程序即可找到。
  - `InstallDir: <子目录>`：把包装到 `~/.pmm/root/<子目录>`，其中 `bin` 也进 PATH、`lib` 是
    `LibraryPath` 指向的对象。
- **`install-ppdm.sh`**：ppdm 开发者工具一键安装脚本（也随 release 产出）。
- **ppdm release 资产按架构命名**：`ppdm` / `ppdm-aarch64` / `ppdm.exe`（避免 amd64/aarch64 冲突）。
- **ppdm 教程**文档；`download.md` 增列 `install-ppdm.sh`。

## 说明
- ppdm 版本不变（仍 `0.0.1`），独立于 PMM。
- `LibraryPath`/`InstallDir` 写入 `/下 `~/.bashrc`，当前 shell 需 `source ~/.bashrc` 或重开生效。
- 修正：解包到 `InstallDir` 前确保目标目录存在（`tar -C` 不再报 Cannot open）。
