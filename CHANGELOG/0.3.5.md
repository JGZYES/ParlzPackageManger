# PMM v0.3.5

## 新增
- **彩色结构化输出**：`[PMM]:[ERROR]`(红)/`[PMM]:[SUCCESS]`(绿)/`[PMM]:[INFO]`(灰)/`[PMM]:[WARN]`(黄)，仅终端变色；`--no-color` / `PMM_NO_COLOR=1` 强制纯文本。
- **输出控制**：`-q`/`--quiet`(只显示错误/警告)、`--verbose`(更多细节)；支持合并短旗标如 `-yq` 等价于 `-y -q`。
- **`pmm update`**(apt 风格刷索引)：下载 `packages.json` + 各包 `.json` 到 `~/.pmm/cache/registry/`。
- **`pmm upgrade [--yes]`**：扫描已装包查 registry 最新版并逐个升级。
- **`pmm mirror check`**：检测各镜像源可达性/优先级(apt 风格源检测)。
- **`pmm info` 增强**：显示描述 + versions 列表。

## 安装
```bash
# Linux/macOS 一键
curl -sSL https://pmm.parlz.com/install.sh | bash
# Windows：解压 pmm-0.3.5-windows-amd64.zip，pmm.exe 加入 PATH
```
